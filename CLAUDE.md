## Commands

- `npm run dev` — start the dev server (Turbopack) at http://localhost:3000
- `npm run build` — production build
- `npm run start` — serve the production build
- `npm run lint` — ESLint (flat config: `eslint-config-next` core-web-vitals + typescript rules)

No test framework is configured (no test script, no test files).

## Architecture

This is an essentially unmodified `create-next-app` scaffold (App Router + TypeScript + Tailwind CSS v4) — a single route defined by `app/layout.tsx` (root layout, Geist fonts via `next/font/google`) and `app/page.tsx` (home page). Global styles live in `app/globals.css`; Tailwind is wired in via `@tailwindcss/postcss` (`postcss.config.mjs`). The `@/*` import alias maps to the repo root (`tsconfig.json`).

Since this repo runs a Next.js version ahead of training data (per `AGENTS.md`, consult `node_modules/next/dist/docs/` before writing routing/caching/data-fetching code), note two renames already visible in this codebase: route files use typed props generated by Next itself (e.g. `RootLayout({ children }: LayoutProps<"/">)` in `app/layout.tsx`), and Middleware has been renamed to **Proxy** (`proxy.js`, not `middleware.js`). There's also a newer caching model ("Cache Components" / the `"use cache"` directive) that supersedes older ISR patterns — check the relevant doc page under `node_modules/next/dist/docs/01-app/` before assuming APIs you already know still apply.
